# Project Coordinator Portfolio — กฤตยชญ์ กุลกลางดอน

เว็บพอร์ตโฟลิโอหน้าเดียว (SPA) สำหรับสมัครตำแหน่ง **Project Coordinator (เจ้าหน้าที่ประสานงานโครงการ)**
เขียนด้วย HTML · CSS · JavaScript ล้วน ไม่มี build step ไม่ใช้เฟรมเวิร์ก ไม่มี Analytics ไม่ใช้คุกกี้

**เว็บไซต์:** https://kridtayod-1988.github.io/portfolio/

## เนื้อหาในเว็บ

| หน้า | สิ่งที่แสดง |
|---|---|
| `home` | ชื่อ ตำแหน่งเป้าหมาย ข้อความแนะนำสั้น ๆ ข้อมูลสถานะ และเกี่ยวกับฉัน |
| `projects` | ผลงานเด่น 3 ชิ้น แยก "ส่วนที่ทำเอง" ออกจาก "ส่วนของทีม" |
| `skills` | ทักษะ 3 กลุ่ม แต่ละทักษะลิงก์ไปยังงานที่เป็นหลักฐาน |
| `experience` | ประสบการณ์ทำงานเรียงตามเวลา และการศึกษา |
| `contact` | อีเมล โปรไฟล์ที่เกี่ยวข้อง และฟอร์มที่เปิดแอปอีเมลของผู้เยี่ยมชม |

## คุณสมบัติ

- **SPA:** สลับหน้าโดยไม่โหลดใหม่ ใช้ปุ่มย้อนกลับของเบราว์เซอร์ได้ และแชร์ลิงก์ตรงหน้าได้ เช่น `/#projects`
- **Dark / Light mode:** เริ่มตามธีมของเครื่อง และจำค่าที่ผู้ใช้เลือก
- **ลิงก์หลักฐาน:** กดชื่อทักษะ → ไปยังผลงานหรือประสบการณ์ที่ใช้ทักษะนั้น พร้อมไฮไลต์
- **รองรับรูปและวิดีโอ:** รูปโปรไฟล์และสื่อประกอบผลงาน (ดู "เพิ่มรูปและวิดีโอ")
- **การเข้าถึง:** ลิงก์ข้ามไปเนื้อหาหลัก, focus ที่มองเห็นชัด, ใช้คีย์บอร์ดได้, ลดแอนิเมชันเมื่อเครื่องตั้ง `prefers-reduced-motion`
- **Responsive:** มือถือ แท็บเล็ต และคอมพิวเตอร์

## โครงสร้างไฟล์

```
portfolio/
├── index.html   # เนื้อหาทั้ง 5 หน้า (แต่ละหน้าคือ <section id="...">)
├── styles.css   # สี ฟอนต์ เลย์เอาต์ (ปรับธีมที่ DESIGN TOKENS บนสุดของไฟล์)
├── main.js      # ธีม, ข้อความพิมพ์ดีดใน terminal, สื่อผลงาน, ฟอร์มติดต่อ, ค่า CONFIG
├── spa.js       # ตัวสลับหน้า, ลิงก์หลักฐาน, skip link, ชื่อแท็บของแต่ละหน้า
├── assets/
│   └── profile.jpg   # รูปโปรไฟล์
├── .nojekyll
└── README.md
```

## ดูบนเครื่องตัวเอง

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย หรือรันเซิร์ฟเวอร์ชั่วคราว:

```bash
python3 -m http.server 8000
# เปิด http://localhost:8000
```

## แก้ไขข้อมูล

| ต้องการแก้ | ไฟล์ / ตำแหน่ง |
|---|---|
| ข้อความ ผลงาน ทักษะ ประสบการณ์ ลิงก์ติดต่อ | `index.html` |
| อีเมลปลายทางของฟอร์ม และข้อความใน terminal | `main.js` ตัวแปร `CONFIG` บนสุดของไฟล์ |
| ชื่อแท็บเบราว์เซอร์ของแต่ละหน้า | `spa.js` ตัวแปร `pageTitles` |
| title, description, ภาพตัวอย่างเมื่อแชร์ลิงก์ | `index.html` ส่วน `<head>` |
| สี ฟอนต์ ขนาดมุม | `styles.css` ส่วน `DESIGN TOKENS` |

### เพิ่มผลงานชิ้นใหม่

1. ใน `index.html` คัดลอก `<article class="project-card" id="project-...">` ทั้งก้อน แล้วเปลี่ยน `id` ให้ไม่ซ้ำ
2. แก้เลขลำดับ ชื่อ ป้ายประเภท และรายละเอียด (บทบาท / เป้าหมาย / ส่วนที่ทำเอง / ส่วนของทีม / เครื่องมือ / ผลลัพธ์)
3. ถ้าผลงานนั้นเป็นหลักฐานของทักษะ ให้เพิ่มลิงก์ในหน้า `skills` ด้วยรูปแบบ:

```html
<a href="#projects" data-target="projects" data-focus="project-xxx">ชื่อผลงาน</a>
```

หลักการเขียนผลงาน: ใส่เฉพาะข้อมูลที่เป็นจริงและตรวจสอบได้ ถ้าไม่มีตัวเลข ให้เขียนสิ่งที่ปรับปรุงหรือสิ่งที่เรียนรู้แทน และแยกส่วนที่ทำเองออกจากส่วนของทีมให้ชัด

## เพิ่มรูปและวิดีโอ

**รูปโปรไฟล์:** แทนที่ไฟล์ `assets/profile.jpg` (แนะนำไม่เกิน 200 KB) ระบบจัดกรอบแบบสี่เหลี่ยมจัตุรัสโดยเน้นส่วนบนของภาพ เหมาะกับรูปหน้าตรงครึ่งตัว หากไม่พบไฟล์ จะแสดงตัวอักษรย่อ "KK" แทน

**รูปหรือวิดีโอประกอบผลงาน:** เพิ่มบล็อกนี้ไว้ต้นการ์ด `<article class="project-card">` (ก่อน `<header class="project-head">`)

```html
<div class="project-media" data-media="assets/demo.mp4">
  <div class="cover cover-a">DEMO</div>
</div>
```

- `data-media` รองรับ `.png .jpg .webp` (แสดงเป็นรูป) และ `.mp4 .webm` (แสดงเป็นวิดีโอ เล่นวนไม่มีเสียง มีปุ่มควบคุม)
- ถ้าโหลดไฟล์ไม่ได้ จะคงแผ่นปก `.cover` ไว้ ไม่มีรูปแตก
- วิดีโอควรสั้นและไม่เกิน 10 MB **ตรวจให้แน่ใจว่าในภาพหรือวิดีโอไม่มีข้อมูลลูกค้า ข้อมูลส่วนบุคคล หรือข้อมูลลับของหน่วยงาน**

## Deploy ด้วย GitHub Pages

เว็บนี้ขึ้นระบบแล้วที่ลิงก์ด้านบน ส่วนนี้ใช้เมื่อต้องการอัปเดตหรือสร้างใหม่

### อัปเดตไฟล์ผ่านหน้าเว็บ GitHub

1. เปิด repo → **Add file → Upload files** แล้วลากไฟล์ที่แก้ไขลงไป (ไฟล์ชื่อเดิมจะถูกแทนที่) ใส่โฟลเดอร์ `assets` ด้วยถ้ามีรูปใหม่
2. กด **Commit changes**
3. รอ 1–2 นาที แล้วรีเฟรชหน้าเว็บ (ถ้ายังเห็นของเดิม ให้กด Ctrl+Shift+R หรือเปิดแบบ Incognito)

### อัปเดตด้วยคำสั่ง Git

```bash
git add .
git commit -m "Update portfolio"
git push
```

### สร้างใหม่ตั้งแต่ต้น

1. สร้าง repo สาธารณะชื่อ `portfolio` อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวม `assets` และ `.nojekyll`)
2. ไปที่ **Settings → Pages** ตรง Source เลือก **Deploy from a branch** แล้วเลือก Branch `main` โฟลเดอร์ `/ (root)` กด **Save**
3. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/portfolio/`

หากย้ายไปใช้ชื่อ repo อื่น ให้แก้ `og:url` และ `og:image` ใน `<head>` ของ `index.html` ให้ตรงกับลิงก์ใหม่ด้วย

ไม่ต้องตั้งค่า redirect เพราะ SPA ใช้ hash (`#home`) ไม่ใช่ path

### ทางเลือก: Netlify

**Add new site → Import an existing project** เลือก repo นี้ ช่อง Build command ปล่อยว่าง ช่อง Publish directory ใส่ `.` หรือลากทั้งโฟลเดอร์ไปวางที่หน้า Deploy manually ได้เลย

## ความเป็นส่วนตัว

repo และเว็บเป็นสาธารณะ ใครก็เห็นได้ ข้อมูลที่แสดงมีเพียง ชื่อ รูปโปรไฟล์ อีเมล โปรไฟล์ Facebook/Fastwork และเขตที่อยู่ ไม่แสดงที่อยู่บ้าน เบอร์โทร วันเกิด ศาสนา เงินเดือน หรือข้อมูลบุคคลอ้างอิง หากต้องการเพิ่มช่องทางติดต่ออื่น ให้เพิ่มในหน้า `contact` ที่ `index.html` โดยพิจารณาก่อนว่าพร้อมเปิดเผยต่อสาธารณะ

## สถานะการทดสอบ

- **ทดสอบแล้ว:** บน Chromium แบบไม่มีหน้าจอ ที่ขนาด 1280px และ 390px — สลับ 5 หน้า, ปุ่มย้อนกลับ, ลิงก์หลักฐานข้ามหน้า, ลิงก์ข้ามไปเนื้อหาหลัก, สลับธีม, เมนูมือถือ, ไม่มี JavaScript error, ไม่มีเลื่อนซ้ายขวาบนมือถือ
- **ยังไม่ได้ทดสอบ:** อุปกรณ์จริง, Safari, Firefox, โปรแกรมอ่านหน้าจอ และการเปิดแอปอีเมลจากฟอร์ม
- ออกแบบให้ contrast อยู่ในเกณฑ์ WCAG AA แต่ยังไม่ได้ตรวจรับรอง
